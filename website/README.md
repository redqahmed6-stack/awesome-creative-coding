# Portfolio page

`portfolio.html` is an additive, dependency-free portfolio page. The original `index.html` homepage is intentionally unchanged.

The portfolio includes only the three repositories that directly represent the personal creative-coding practice: [Pts.js](https://github.com/redqahmed6-stack/pts), [css-doodle](https://github.com/redqahmed6-stack/css-doodle), and [Workshop Generative Art](https://github.com/redqahmed6-stack/workshop-generative-art). Curated resource repositories and unrelated material are not shown in the portfolio.

The page is responsive, keyboard-friendly, and uses semantic sections, visible focus behavior, and direct links to the source repositories. It has no build step or external dependency, so it can be served directly from GitHub Pages.
